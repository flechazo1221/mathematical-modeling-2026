# H0 中性选择包（仅 A/B/C）

## 决策问题

团队需要在 A、B、C 中选择一个进入 H0 后的人工批准流程。最终选题属于 `TEAM_REQUIRED`；本包不构成批准。

## 不可改变事实

* C：全年负载/光伏/价格与预报数据及模板已在 input 中可读。
* A：热质传递参数、半径历史和四类结果模板已在 input 中可读。
* B：核心正式测试依赖外部模拟器；项目 input 仅含题面和协议 DOCX。
* 固定评分权重为 25/15/20/15/25；不得用总分掩盖 hard stop。

## 比较结果

`C 84.0 > A 78.5 > B 52.5`。C 的优势是数据和约束完整、可逐时复算；A 的优势是题意清楚且数据小，但移动边界数值风险较高；B 的核心证据链受外部模拟器和正式测试可用性限制。

## 非约束性 AI 建议

若仅以当前可复现性和验证闭环作参考，建议团队优先核查 C，再比较 A；B 只有在模拟器可用性和演练证据补齐后才适合进入 H1。该建议不替代团队选择。

## H0 前需人工确认

1. 选定唯一候选 id（A/B/C）。
2. 核对 `input/format2026.doc` 官方格式条款。
3. 若考虑 B，确认模拟器下载、账号、联网、三次正式测试和日志导出条件。
4. 若考虑 A/C，确认上述各自的移动边界或结算/预测口径。

团队批准后由真实队员创建 `decisions/H0-selection.json`；在此之前保持 SELECTION 等待，不启动 INTAKE。

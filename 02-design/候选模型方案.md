# 模型候选方案——统一相容性框架


## 1. 总体建模原则

本题不将各小问分别建立为相互独立的模型，而是先建立一个统一的二维守恒母模型，再根据不同问题对空间维度、物理机制和参数复杂度进行降阶或扩展。

整体模型族采用如下结构：

[  
\boxed{  
\text{统一二维母模型}  
\rightarrow  
\text{一维降阶}  
\rightarrow  
\text{二维基础模型}  
\rightarrow  
\text{二维非线性/耦合模型}  
\rightarrow  
\text{预测与优化模型}  
}  
]

其中所有候选模型共享：

- 同一物理区域定义；
    
- 同一附件数据；
    
- 同一 H1 数据插值与延拓规则；
    
- 同一初始条件；
    
- 同一边界条件定义；
    
- 同一物性关系；
    
- 同一状态变量转换关系；
    
- 同一输出时刻与评价位置；
    
- 同一误差指标；
    
- 同一阈值定义；
    
- 同一计算资源约束。
    

不同模型仅允许在以下方面变化：

1. 空间维度；
    
2. 保留的物理机制；
    
3. 参数是否为常数或状态相关函数；
    
4. 是否考虑额外耦合项。
    

由此保证不同模型之间具有严格的可比性。

---

# 2. 状态变量统一

必须首先区分以下物理量：

[  
X  
]

表示材料内部含水率；

[  
\phi  
]

表示相对湿度；

[  
c_v  
]

表示水蒸气浓度；

[  
p_v  
]

表示水蒸气分压；

[  
T  
]

表示温度。

这些变量具有不同的物理意义和量纲，因此不得直接相减或混用。

例如：

[  
X-\phi  
]

没有直接物理意义。

若附件给出的是相对湿度，而模型内部求解的是含水率，则必须通过统一的平衡关系：

[  
X=X_{\mathrm{eq}}(\phi,T)  
]

进行转换。

反之：

[  
\phi=\phi(X,T).  
]

因此建立统一转换层：

[  
\boxed{  
(X,T)  
\leftrightarrow  
\phi  
\leftrightarrow  
p_v  
\leftrightarrow  
c_v  
}  
]

所有候选模型最终必须转换到与附件观测数据相同的物理量后，再计算误差。

因此模型评价统一写为：

[  
E=  
\mathcal E  
\left(  
y_{\mathrm{pred}},  
y_{\mathrm{obs}}  
\right),  
]

其中 (y_{\mathrm{pred}}) 与 (y_{\mathrm{obs}}) 必须表示相同物理量。

---

# 3. 统一二维母模型

将整个问题首先描述为二维非稳态守恒问题。

设主状态变量为：

[  
u(x,y,t).  
]

其中 (u) 可以根据最终数据口径选为含水率、浓度或其他守恒状态量。

统一母方程写为：

\nabla\cdot  
\left[  
D(u,T,\mathbf x)  
\nabla u  
\right]  
+  
S(u,T,\mathbf x,t).  
]

二维展开：

\frac{\partial}{\partial x}  
\left(  
D_x  
\frac{\partial u}{\partial x}  
\right)  
+  
\frac{\partial}{\partial y}  
\left(  
D_y  
\frac{\partial u}{\partial y}  
\right)  
+  
S.  
]

其中：

[  
C  
]

表示等效储存能力；

[  
D_x,D_y  
]

分别表示两个方向上的有效传输系数；

[  
S  
]

表示源汇项。

若材料近似各向同性：

[  
D_x=D_y=D.  
]

若存在方向性结构，则保留：

[  
D_x\neq D_y.  
]

该二维模型作为所有后续候选的“母模型”。

---

# 4. 边界条件统一

所有候选模型使用统一边界物理定义。

对于与环境发生交换的边界，采用 Robin 边界：

h_m  
\left(  
u_s-u_\infty  
\right).  
]

其中：

- (\mathbf n)：边界外法向；
    
- (u_s)：表面状态；
    
- (u_\infty)：环境状态；
    
- (h_m)：等效传质系数。
    

如果实际边界关系使用相对湿度或蒸气分压，则必须先通过统一状态关系进行转换。

例如：

h_p  
\left(  
p_{v,s}-p_{v,\infty}  
\right).  
]

不能在一个模型中采用：

[  
X_s-X_\infty  
]

而另一个模型采用：

[  
RH_s-RH_\infty  
]

后直接比较传质系数。

所有候选必须使用相同的边界物理口径。

---

# 5. Q1：一维—二维相容模型

Q1同时建立一维和二维模型，但一维模型不得作为独立经验模型，而必须是二维母模型的严格降阶。

二维模型：

\frac{\partial}{\partial x}  
\left(  
D_x  
\frac{\partial u}{\partial x}  
\right)  
+  
\frac{\partial}{\partial y}  
\left(  
D_y  
\frac{\partial u}{\partial y}  
\right).  
]

若横向梯度可以忽略：

[  
\frac{\partial u}{\partial y}\approx0,  
]

则得到：

\frac{\partial}{\partial x}  
\left(  
D_x  
\frac{\partial u}{\partial x}  
\right).  
]

因此：

M_{2D}  
\Big|  
_{\partial u/\partial y=0}  
}  
]

这保证一维和二维模型在数学结构上严格相容。

---

## 5.1 一维候选 M1

模型：

\frac{\partial}{\partial x}  
\left(  
D  
\frac{\partial u}{\partial x}  
\right).  
]

用途：

- 建立基准模型；
    
- 初步识别主要参数；
    
- 判断主要变化是否沿单一方向传播；
    
- 提供计算速度较快的参照结果。
    

---

## 5.2 二维候选 M2

模型：

\nabla\cdot(D\nabla u).  
]

用途：

- 描述边缘和角部效应；
    
- 描述横向不均匀性；
    
- 判断一维假设是否充分。
    

定义一维—二维差异指标：

\frac{  
\left|  
\bar u_{2D}-u_{1D}  
\right|_2  
}{  
\left|  
\bar u_{2D}  
\right|_2+\varepsilon  
}.  
]

其中：

\frac1{L_y}  
\int_0^{L_y}  
u(x,y,t),dy.  
]

若：

[  
E_{\mathrm{dim}}\ll1,  
]

则说明一维模型具有较好的合理性。

若：

[  
E_{\mathrm{dim}}  
]

明显增大，则后续问题优先采用二维模型。

---

# 6. Q2：二维非线性模型

Q2不重新建立模型，而是在 Q1 的二维模型基础上增加状态相关物性。

基础模型：

\nabla\cdot(D\nabla u).  
]

扩展为：

\nabla\cdot  
\left[  
D(u,T)  
\nabla u  
\right].  
]

例如：

[  
D=D(u),  
]

或：

[  
D=D(u,T).  
]

这样：

[  
M_2  
\subset M_3.  
]

即当：

[  
D(u,T)=D_0  
]

时，Q2 模型自动退化为 Q1 的二维基础模型。

因此两个模型严格嵌套。

Q2重点研究：

[  
\boxed{  
\text{非线性物性是否能够显著改善模型解释能力}  
}  
]

而不是重新建立另一套传输方程。

---

# 7. Q3：二维耦合模型

若 Q2 的单一状态变量仍无法解释附件数据，则在原模型上增加第二个物理场。

例如考虑热—湿耦合：

\nabla\cdot  
\left(  
k\nabla T  
\right)  
+  
Q.  
]

同时：

\nabla\cdot  
\left[  
D(u,T)  
\nabla u  
\right]  
+  
S(u,T).  
]

于是得到：

[  
\boxed{  
u  
\leftrightarrow  
T  
}  
]

的耦合系统。

温度影响：

[  
D=D(u,T),  
]

而水分迁移又可以通过：

[  
Q=Q(u,\partial u/\partial t)  
]

反过来影响温度。

因此形成：

[  
M_1  
\subset  
M_2  
\subset  
M_3  
]

的嵌套关系。

其中：

- M1：一维基础模型；
    
- M2：二维基础模型；
    
- M3：二维非线性/耦合模型。
    

只有在新增机制能够显著改善模型效果时，才保留复杂模型。

---

# 8. 模型复杂度选择原则

不采用“模型越复杂越好”的原则，而采用逐级增加机制的方式。

模型升级顺序：

[  
M_1  
\rightarrow  
M_2  
\rightarrow  
M_3.  
]

每次加入新机制，都比较：

## E_{\mathrm{old}}

E_{\mathrm{new}}.  
]

同时考虑复杂度增长：

## C_{\mathrm{new}}

C_{\mathrm{old}}.  
]

只有当：

[  
\Delta E  
]

足够明显，且计算代价可接受时，才保留更复杂模型。

因此最终选择依据不是单纯最低误差，而是：

[  
\boxed{  
\text{准确度}  
+  
\text{物理解释性}  
+  
\text{数值稳定性}  
+  
\text{计算成本}  
}  
]

综合评价。

---

# 9. 数值方法统一

空间离散优先采用保守有限体积法 FVM。

二维控制方程：

\nabla\cdot(D\nabla u)+S  
]

在控制体 (V_P) 上积分：

\oint_{\partial V_P}  
D\nabla u\cdot\mathbf n,dA  
+  
\int_{V_P}S,dV.  
]

采用通量形式离散，以保证：

[  
\boxed{\text{局部守恒}}  
]

和：

[  
\boxed{\text{全局守恒}}.  
]

时间方向优先考虑：

- Backward Euler；
    
- Crank–Nicolson；
    
- 或稳定的隐式格式。
    

一维和二维模型使用相同的离散思想，而不是完全不同的求解方法。

---

# 10. 计算网格与评价网格分离

不同模型不强制使用相同计算网格。

一维模型使用：

[  
N_x  
]

个单元；

二维模型使用：

[  
N_x\times N_y  
]

个单元。

但所有模型统一输出到相同的评价位置与评价时刻。

即：

[  
\boxed{  
\text{计算网格}  
\neq  
\text{评价网格}  
}  
]

模型结果通过插值映射至统一评价网格：

\mathcal I  
\left(  
u_{\mathrm{numerical}}  
\right).  
]

随后再与附件数据比较。

---

# 11. 网格独立性

对主要模型至少采用三级网格：

[  
G_1,\quad  
G_2,\quad  
G_3.  
]

例如：

[  
N_x\times N_y,  
]

[  
2N_x\times2N_y,  
]

[  
4N_x\times4N_y.  
]

比较：

\frac{  
|u_{G_2}-u_{G_3}|  
}{  
|u_{G_3}|  
}.  
]

若：

[  
E_{\mathrm{grid}}<\varepsilon_g,  
]

则认为达到网格收敛。

因此模型间比较不会被网格粗细差异污染。

---

# 12. 参数共享原则

对于不同候选模型中的相同物理参数：

[  
D,  
\quad  
h_m,  
\quad  
C,  
\quad  
k,  
]

必须保持相同定义。

若同一个 (D) 在不同模型中采用不同数值，则必须明确说明：

[  
D^{(M_i)}  
]

是重新反演得到的模型有效参数，而不能假装它们代表完全相同的物性。

最好采用两种比较方式。

第一种：

[  
\boxed{\text{固定参数比较}}  
]

用于判断新增机制本身产生的效果。

第二种：

[  
\boxed{\text{重新标定比较}}  
]

用于评价每个模型的最佳拟合能力。

二者不得混淆。

---

# 13. Q1 → Q2 → Q3 数据流

整个问题采用连续的数据流：

[  
\boxed{  
\text{附件数据}  
}  
]

↓

[  
\boxed{  
\text{H1 数据清洗/插值/延拓}  
}  
]

↓

[  
\boxed{  
\text{统一物性函数}  
}  
]

↓

[  
\boxed{  
Q1：1D/2D 基础模型  
}  
]

↓

判断二维效应

↓

[  
\boxed{  
Q2：二维非线性模型  
}  
]

↓

判断额外机制是否必要

↓

[  
\boxed{  
Q3：二维耦合模型  
}  
]

↓

↓

[  
\boxed{  
Q4：预测/优化  
}  
]

因此不存在：

[  
Q1\rightarrow\text{结束}  
]

然后：

[  
Q2\rightarrow\text{重新开始建模}  
]

的问题。

# 14. Q4：统一模型驱动的预测与优化

Q4不新建独立模型。

将经过 Q1–Q3 验证后的最终模型表示为：

\mathcal F  
(  
\mathbf z,  
\mathbf p,  
\mathbf b,  
\mathbf x_0  
).  
]

其中：

[  
\mathbf z  
]

表示可控决策变量；

[  
\mathbf p  
]

表示物性参数；

[  
\mathbf b  
]

表示边界条件；

[  
\mathbf x_0  
]

表示初始条件。

模型输出：

[  
\mathbf y  
]

包括：

- 最终状态；
    
- 时间历程；
    
- 二维场分布；
    
- 平均状态；
    
- 极值；
    
- 达到阈值所需时间等。
    

Q4在该求解器外构建目标函数：

[  
\min_{\mathbf z}  
J  
\left[  
\mathcal F(\mathbf z)  
\right].  
]

或者：

[  
\max_{\mathbf z}  
J  
\left[  
\mathcal F(\mathbf z)  
\right].  
]

并加入约束：

[  
g_i(\mathbf z)\le0.  
]

因此 Q4 本质上是：

[  
\boxed{  
\text{PDE forward model}  
+  
\text{optimization}  
}  
]

而不是第四套模型。

# 15. 候选模型最终结构

建议保留以下核心候选。

### M1：一维基准模型

\frac{\partial}{\partial x}  
\left(  
D  
\frac{\partial u}{\partial x}  
\right).  
]

用途：

- 基准；
    
- 快速参数识别；
    
- 检验一维假设。
    

---

### M2：二维基础传输模型

\nabla\cdot(D\nabla u).  
]

用途：

- 描述二维空间非均匀性；
    
- 边缘效应；
    
- 角部效应；
    
- 验证一维近似。
    

---

### M3：二维非线性模型

\nabla\cdot  
\left[  
D(u,T)\nabla u  
\right].  
]

用途：

描述状态依赖的有效传输特性。

---

### M4：二维耦合模型

\nabla\cdot(k\nabla T)  
+  
S_T.  
\end{cases}  
]

用途：

仅当单场模型出现系统性偏差时启用。

---

模型之间满足：

[  
\boxed{  
M_1  
\subset  
M_2  
\subset  
M_3  
\subset  
M_4  
}  
]

至少在适当参数极限下能够逐级退化。

这构成整个模型候选方案最重要的相容性条件。

---

# 16. 模型相容性检查

每个候选模型进入正式比较之前必须通过以下检查。

## ① 状态变量相容

确认：

[  
y_{\mathrm{model}}  
]

与：

[  
y_{\mathrm{data}}  
]

表示同一物理量。

---

## ② 量纲相容

检查方程每一项：

\left[  
\nabla\cdot(D\nabla u)  
\right].  
]

---

## ③ 边界相容

确认各模型采用相同的：

- 通量方向；
    
- 环境变量；
    
- 边界传递系数定义。
    

---

## ④ 参数相容

同名参数必须具有相同的物理意义。

---

## ⑤ 维度相容

验证：

[  
M_{2D}  
\rightarrow  
M_{1D}  
]

在横向均匀条件下成立。

---

## ⑥ 机制退化相容

例如：

[  
D(u,T)=D_0  
]

时：

[  
M_3\rightarrow M_2.  
]

若关闭耦合：

[  
S_T=0,  
]

且温度固定：

[  
T=T_0,  
]

则：

[  
M_4\rightarrow M_3.  
]

---

## ⑦ 数值相容

所有模型：

- 使用保守离散；
    
- 使用统一误差计算方法；
    
- 完成网格收敛；
    
- 统一输出时刻。
    

---

# 17. 暂缓模型的引入条件

完整多孔多相 CFD、PINN、GNN 和纯机器学习不与 M1–M4 平行竞争，而仅作为后续扩展路线。

## 多孔多相 CFD

当出现以下情况时考虑：

- 单场有效扩散模型持续出现结构性误差；
    
- 明显存在气液多相迁移；
    
- 毛细作用和压力驱动不能忽略；
    
- 局部流动对结果具有决定作用。
    

即：

[  
\boxed{  
\text{现有 PDE 物理机制不足}  
\Rightarrow  
\text{多孔多相 CFD}  
}  
]

---

## PINN

当：

- PDE 已经比较可信；
    
- 参数反演困难；
    
- 数据稀疏；
    
- 需要同时利用 PDE 和测量数据，
    

才考虑 PINN。

PINN 不作为替代基本 PDE 建模的工具。

---

## GNN / 神经算子 / 代理模型

当已经拥有大量高保真模拟样本：

[  
{  
\mathbf x_i,\mathbf y_i  
}_{i=1}^{N}  
]

且需要：

- 大量重复工况预测；
    
- 大规模参数扫描；
    
- 优化中反复调用 PDE；
    
- 实时预测，
    

才考虑建立代理模型：

[  
\hat{\mathcal F}  
\approx  
\mathcal F_{\mathrm{PDE}}.  
]

---

## 纯机器学习

只有当拥有足够独立实验数据，而且问题目标转变为纯预测时，才作为额外候选。

不能以纯机器学习模型替代本题所要求的物理机制分析。

---

# 18. 最终模型体系

最终建议将整个方案概括为：

[  
\boxed{  
\begin{array}{c}  
\text{附件实验数据}\  
\downarrow\  
\text{统一状态量与物性关系}\  
\downarrow\  
\text{二维守恒母模型}\  
\downarrow\  
\begin{array}{ccc}  
M_1\text{：1D}  
&  
\longleftrightarrow  
&  
M_2\text{：2D}  
\end{array}\  
\downarrow\  
M_3\text{：2D nonlinear}\  
\downarrow\  
M_4\text{：2D coupled}\  
\downarrow\  
\text{验证与模型选择}\  
\downarrow\  
\text{Q4 prediction / optimization}  
\end{array}  
}  
]

其核心思想不是为每道问题寻找一个完全不同的模型，而是：

[  
\boxed{  
\text{同一个物理模型逐步增加必要复杂度}  
}  
]

从而保证：

[  
\boxed{  
\text{物理相容}  
+  
\text{数学相容}  
+  
\text{参数相容}  
+  
\text{数值相容}  
+  
\text{数据相容}  
}  
]

并使最终形成的 Q1–Q4 成为一个连续、统一的建模体系。

# 术语与符号表

本表与新版《候选模型方案——统一相容性框架》和《A题“药材的烘干问题”DESIGN 题目分析报告》保持一致。所有候选模型必须先把预测量与附件观测量转换为同一物理量，再进行误差计算；同名参数在不同模型中保持相同物理定义。

## 状态量、坐标与物性

| 符号/术语 | 定义 | 单位/域 | 统一口径与禁用规则 |
|---|---|---|---|
| `r,z` | 圆柱径向坐标与轴向坐标 | m | 一维模型只保留 `r`；二维轴对称模型使用 `(r,z)`，不得把 `z` 误作周向坐标 |
| `t` | 烘干时间 | s | 对外报告时可换算为 h |
| `T(r,z,t)` | 材料内部局部温度 | K（计算） | 展示时可换算为 °C；指数经验式统一使用 K |
| `C(r,z,t)` | 材料干基含水率，即水质量/干固体质量 | kg/kg | 本项目统一用 `C`；不与空气相对湿度、蒸气浓度或分压直接混用 |
| `φ` | 相对湿度 | 0–1 或 % | 使用前必须统一百分数与小数口径；不等同于含水率 `C` |
| `c_v` | 水蒸气浓度 | kg/m³ | 不与材料干基含水率混用 |
| `p_v` | 水蒸气分压 | Pa | 通过状态关系与 `φ`、`c_v` 转换 |
| `C_eq(φ,T)` | 给定相对湿度和温度下的平衡干基含水率关系 | kg/kg | 只有采用该边界闭合时使用；构成状态转换层，不得凭空定参 |
| `ρ(C)` | 题面给定的有效物料体积密度 | kg/m³ | Q1–Q4 按相应附录用于能量方程；Q4 中不强制把它等同于局部干固体密度 |
| `ρ_d` | 干固体体积密度 | kg dry solid/m³ | Q4 中由给定材料速度下的干固体连续性从初值推进；`ρ(C)/(1+C)` 仅在物理定义得到证明后作兼容性对照 |
| `q_w=ρ_d C` | 单位当前体积的水质量 | kg water/m³ | Q4 物理含水库存的守恒变量；不得用 `∫C dV` 代替水质量 |
| `c_p(C)` | 比热容 | J/(kg·K) | 按题面各问物性关系更新 |
| `D(C,T)` | 有效水分扩散系数 | m²/s | Q1 为 `D(C)`，Q2–Q4 为 `D(C,T)`；温度用 K |
| `k(C)` | 导热系数 | W/(m·K) | Q1–Q4 温度方程均使用；不与扩散系数 `D` 混用 |
| `S_T,S_C` | 温度/含水率方程源项 | 与对应守恒方程一致 | 最低充分模型取 0；只有参数可识别且验证证明必要时启用 |

## 边界、输出与评价

| 符号/术语 | 定义 | 单位/域 | 统一口径与禁用规则 |
|---|---|---|---|
| `Ω(t)` | 时刻 `t` 的材料物理区域 | m²（二维） | 固定域时简写为 `Ω`；若边界变化必须显式保留时间依赖 |
| `𝐧` | 边界外法向单位向量 | 无量纲 | 所有候选统一采用外法向和通量符号约定 |
| `T_s,T_∞` | 材料表面温度与烘房温度 | K | Robin 换热边界两端使用同一温标 |
| `C_s,C_∞` | 材料表面与题设环境水分状态 | kg/kg（题设有效口径） | 本项目遵循 H1 的 `C_s-C_∞`；不得与 RH 差或分压差混用 |
| `h_m` | 等效对流传质系数 | m/s | 仅能配合已统一口径的传质势差；不与扩散系数 `D` 混用 |
| `h_p` | 以水蒸气分压差定义的边界传递系数 | 由分压通量式确定 | 不能与基于含水率差或相对湿度差定义的系数直接比较 |
| `y_pred,y_obs` | 模型预测量与附件观测量 | 必须相同 | 计算误差前须经统一状态转换和评价网格映射 |
| `ℰ(·,·)`、`E` | 统一误差函数及其取值 | 由所选指标决定 | 所有候选使用相同数据、时刻、位置和误差定义 |
| `⟨u⟩_z` | 二维轴对称解沿半长度的轴向平均 | 与 `u` 相同 | 本轮统一作为径向评价/导出算子；不得用于替代 Q3/Q4 的二维全域最大值 |
| `E_dim` | 一维解与二维轴向平均解的相对差异指标 | 无量纲 | 差异须与联合离散误差和输出分辨率比较 |
| `ε_0` | 相对差异公式中的防零小量 | 与相应范数相同 | 仅用于数值稳定，不得调节以人为缩小误差 |
| `ε_C` | 阈值比较容差 | `10^-6 kg/kg` | 采用单侧安全判定 `C_max≤0.15-ε_C`；未决带继续加密 |
| `t_*`,`t_rep` | 首次安全时刻与 60 s 口径报告时刻 | s | `t_rep=60 ceil(t_*/60)`，并核验前一输出时刻未达标 |
| `𝓘` | 将数值解映射到统一评价网格的插值算子 | — | 计算网格可不同，但评价位置和评价时刻必须相同 |

## 候选模型与数值离散

| 符号/术语 | 定义 | 单位/域 | 统一口径与启用条件 |
|---|---|---|---|
| 统一二维母模型 | 圆柱轴对称温度—含水率非稳态守恒方程 | PDE | Q1–Q4 共享状态、边界、符号与离散思想，按物性和几何逐步扩展 |
| Q1-1D | 一维径向固定域基线 | 1D PDE | 与 Q1-2D 使用同一物性和侧面边界；用于基线与端面假设检验 |
| Q1-2D | 二维轴对称固定域诊断模型 | 2D PDE | 显式包含端面通量，用于评估端面效应 |
| Q2/Q3-2D | 二维轴对称状态相关固定域候选主模型 | nonlinear 2D PDE | Q2 输出 3 h 场，Q3 续算全域阈值事件；一维仅作对照/敏感性/验证 |
| Q4-2D | 二维轴对称移动边界候选主模型 | moving-domain 2D PDE | 半径 `R(t)` 变化，必须满足几何与水分守恒；一维移动域只作降阶对照 |
| M1-Q4 | 固定参考域变换离散候选 | ALE/reference-domain FVM | 与 M2-Q4 公平原型比较；H2 前不预选 |
| M2-Q4 | 前沿贴合移动有限体积候选 | moving FVM | 与 M1-Q4 公平原型比较；H2 前不预选 |
| FVM | 保守有限体积法 | 数值方法 | 一维、二维及移动域均优先采用通量形式离散，以审计局部与全局守恒 |
| `V_P` | 以节点/单元 `P` 为代表的控制体 | m、m² 或 m³ | 具体量纲由一维/二维及几何定义确定 |
| Backward Euler | 后向欧拉隐式时间格式 | 数值方法 | 候选时间离散之一，优先保证稳定性和一致比较 |
| Crank–Nicolson | 二阶隐式时间格式 | 数值方法 | 候选时间离散之一，需检查振荡与时间步收敛 |
| `N_r,N_z` | 径向、轴向计算单元数 | 正整数 | 一维使用 `N_r`；二维使用 `N_r×N_z` |
| `G_1,G_2,G_3` | 由粗到细的三级计算网格 | — | 用于网格独立性检查，不等同于评价网格 |
| `E_grid` | 中、细网格数值解的相对差异 | 无量纲 | 与预设容差 `ε_g` 比较 |
| `ε_g` | 网格收敛判据 | 无量纲 | 必须在查看最终比较结果前确定 |
| `D^(M_i)` | 模型 `M_i` 重新标定得到的有效传输参数 | 与 `D` 相同 | 必须标明为模型有效参数，不能冒充跨模型完全相同的材料物性 |
| 固定参数比较 | 各候选共享同一参数值的比较 | — | 用于隔离新增机制本身的影响 |
| 重新标定比较 | 各候选分别估计参数后的比较 | — | 用于比较各模型最佳拟合能力；不得与固定参数比较混合解释 |

## 移动边界与扩展路线

| 符号/术语 | 定义 | 单位/域 | 统一口径与启用条件 |
|---|---|---|---|
| `R(t)` | 药材当前半径 | m | 附件 2 数据经 PCHIP 保形单调插值；Q1–Q3 固定为 `R_0` |
| `ξ=r/R(t)` | Q4 固定参考域径向坐标 | `[0,1]` | 参考域方法必须保留 Jacobian 与 `Rdot` 引起的网格输运项 |
| `v_m` | 材料速度 | m/s | 固定长度、仿射径向收缩基线为 `(r Rdot/R,0)` |
| `v_g` | 数值网格速度 | m/s | 只进入 ALE 相对控制面通量，不得冒充材料速度 |
| `M_w` | 活动域水库存 `∫q_w dV` | kg 或归一化单位 | 未知绝对 `ρ_d,0` 时只审计归一化平衡，不声称绝对水质量 |
| `g_3(t),g_4(t)` | Q3/Q4 全域阈值事件函数 | kg/kg | 定义为活动域 `max C-0.15`，不得用平均值或局部点替代 |
| 多孔多相 CFD | 显式描述气液多相与局部流动的扩展模型 | — | 仅在有效扩散模型持续出现结构性误差且多相机制不可忽略时考虑 |
| PINN | 物理信息神经网络 | — | 仅在 PDE 较可信、数据稀疏且参数反演困难时考虑，不替代基本 PDE 建模 |
| GNN / 神经算子 / 代理模型 | 以高保真模拟样本逼近 PDE 求解器的快速模型 | — | 仅在样本充足且需要大量重复预测、扫描或优化调用时考虑 |
| 纯机器学习模型 | 仅从数据学习输入—输出关系的预测模型 | — | 只有独立实验数据充足且目标转为纯预测时才作为额外候选 |

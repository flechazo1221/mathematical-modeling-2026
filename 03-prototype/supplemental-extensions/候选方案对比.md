# 补充模型原型比较

本实验不替换 M1–M4。标签来自实际运行的低分辨率 M3/M4 求解器或可解析扩散基准，没有独立实验数据。

## 主要区别

- 缩减双相 CFD 显式分离液态与气态库存，质量守恒误差为 1.321e-12，相对单场模型的平均含水量差为 2.330e-02。它增加机制解释，也增加参数不可识别风险。
- PINN-ELM 在稀疏合成观测下反演扩散系数，相对误差 0.00%；场 RMSE 为 3.507e-03，无物理约束基线为 6.330e-02。这只证明规范化扩散原型的数值可行性。
- 固定邻接图代理的内插场 RMSE 为 9.394e-02，外推 RMSE 为 9.449e-02；单次推理约 7.183e-07 s，而低分辨率 PDE 中位求解约 1.136e+00 s。
- 纯 ML 对事件时间的内插 RMSE 为 4212.3 s，外推 RMSE 为 5620.2 s；它最快，但没有守恒、PDE 约束或物理参数解释。

## 结论边界

这些是 120 工况、工况级 72/16/16/16 划分的最小真实原型，并对随机 PINN 与图代理执行三个注册种子。数据量敏感性只在已有降级对照中完成，设计包所列全部训练/消融次数及高分辨率阈值验证仍未完整执行，因此不能把任何补充模型升级为正式主路线。

# PROTOTYPE 候选方案对比

## 1. 口径与执行边界

本阶段只完成小型、可复现原型，不替团队作 H2 选择，也不产生正式 `result1`—`result4`。输入附件保持只读，全部新增文件位于 `03-prototype/`。

当前 H1 的候选标识是：M1=一维基础模型，M2=二维基础传输模型，M3=二维状态相关非线性模型，M4=二维热湿耦合模型。上游旧合同中的 `B1-Q1-radial-FV` 映射到当前 M1；`B23-state-dependent-radial-FV` 仅提供 Q2/Q3 经验式，其一维几何被当前 H1 的二维要求覆盖；旧 `M1-Q4-reference-domain` 与 `M2-Q4-front-fitted-moving-FV` 是 Q4 的两种数值实现，不是当前 H1 的 M1/M2 物理层级。本映射只在本阶段记录，未回写上游。

## 2. 公平原型合同

- 数据：附件1的 241 行环境序列，显式核对首时刻 0 s、末时刻 14400 s；附件2的 145 行半径序列，显式核对首时刻 0 s、末时刻 259200 s。
- 初值与边界：`T=28 °C`、`C=2.55 kg/kg`，`h=25 W/(m²·K)`、`hm=8e-7 m/s`，附件1分段线性插值。
- 数值法：单元中心守恒有限体积、显式时间推进、轴心零通量、外表面 Robin 等效导通系数；二维模型同时包含圆柱侧面和两个端面。
- 比较切片：M1/M2 共用 0—1800 s；M2 常物性、M3、M4 共用 0—10800 s、`10×12` 网格和 2 s 步长。
- 停止规则：到达统一切片末时刻；本原型未把 3 h 内未发生的 `max C<0.15` 事件外推为烘干时长。
- 随机种子：20260911（算法确定性，记录用于复现约定）。
- 复现命令：在项目根运行 `python 03-prototype/run_all.py`；各目录也可运行 `python run.py`。

## 3. 真实运行摘要

| 比较 | 基准结果 | 新机制结果 | 差异与代价 | 证据判定 |
|---|---:|---:|---:|---|
| M1→M2，1800 s 平均 C | 2.298139 | 2.288699 | -0.009440；运行 0.280→0.508 s | 初步可见端面总量效应，但中面中心/表面 C 差小于 `4e-13`；空间收敛未达四位小数，故不支持直接保留 M2 |
| M2 常物性→M3，3 h 平均 C | 1.465039 | 1.317491 | -0.147548；运行 2.104→2.149 s | 数值差异明显，但无内部观测可判拟合增益；方向受参数组合扰动影响，结论为不确定 |
| M3→M4，3 h 平均 C | 1.317491 | 1.340137 | +0.022646；中心温度低 0.341874 °C；运行 2.149→3.794 s | 联立内部温度场改变结果且成本约增 77%；因潜热/双向源项未由题面识别，保留证据不充分 |

所有 15 次运行均未出现负含水率、非有限状态或温度越界。归一化水分守恒误差最大为 `1.22e-14`，说明离散更新的全局收支闭合；这不等价于网格收敛。

## 4. 收敛、敏感性与失败

- M1 基准到细网格：1800 s 表面 C 由 1.508765 变为 1.509828，平均 C 由 2.298139 变为 2.295887；四位小数未稳定。
- M2 基准到细网格：表面 C 同样变化约 0.001063，平均 C 由 2.288699 变为 2.284780；二维端面边界层仍未解析到四位小数。
- M3 将时间步 2 s 减至 1 s：中心、表面和平均 C 的最大变化约 `2.08e-5`。
- M4 将时间步 2 s 减至 1 s：上述含水率最大变化约 `2.04e-5`，中心温度变化约 `6.8e-5 °C`。
- 在运行前冻结的组合扰动为低干燥情景 `(h,hm,D前因子)×0.8、D指数×1.2` 和高干燥情景 `(h,hm,D前因子)×1.2、D指数×0.8`。M3 的 3 h 平均 C 范围为 1.154770—1.499426；M4 为 1.175450—1.523709。参数不确定性影响远大于 M3/M4 基准差，候选排序不稳健。
- 首轮程序把二维平均值除以单层体积，导致均值错误放大；该实现缺陷已修复，全部结果重跑。错误结果未进入本文件或 handoff。

## 5. 可解释性、数据适配与失效模式

| 候选 | 可解释性 | 数据适配 | 主要成本 | 主要失效模式 |
|---|---|---|---|---|
| M1 | 高 | 适合径向基线 | 最低 | 忽略端面及轴向梯度 |
| M2 | 高 | 符合当前 H1 二维母模型 | 约为 M1 基准 1.8 倍 | 端面薄边界层需更细轴向网格 |
| M3 | 中高 | 使用附录3状态相关经验式 | 与本次 M2 常物性相近 | 参数敏感、缺少内部观测，增益不可识别 |
| M4 | 中 | 温度场与扩散系数联立 | 本次约为 M3 1.77 倍 | 题面未给潜热或完整双向耦合源，易把受控简化误称完整耦合 |

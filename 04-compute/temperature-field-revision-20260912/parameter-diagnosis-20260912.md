# 不含潜热的参数归因诊断

本记录只针对温度场修正版，未加入潜热源项。灵敏度算例使用 `nr=10,
nz=20, dt=60 s` 的诊断网格；绝对达标时刻不用于替代正式细网格答案，
只用于判断因素的相对影响量级。

## 1. 当前方程和参数位置

热场采用

\[
\rho c_p\,\partial_tT=\nabla\cdot(k\nabla T),\qquad
-k\nabla T\cdot n=h(T_s-T_\infty).
\]

水分场采用

\[
\partial_tC=\nabla\cdot(D(C,T)\nabla C),\qquad
-D\nabla C\cdot n=h_m(C_s-C_\infty).
\]

Q4 另外使用给定的 `R(t)`、固定参考域守恒离散和
`rho_d=820(R0/R)^2` 的干固体连续性闭合。

## 4. 归因结论

1. `h`、`k`、`rho`、`c_p` 不是当前 Q3/Q4 小时级差异的首要来源。内部温度在 3 h 左右已接近 50 °C，长期过程中热场对水分扩散的反馈有限。
2. `hm` 和尤其是 `D(C,T)` 的经验式是首要检查对象。这里的 `D` 前因子、指数系数、温度单位、含水率变量口径以及 `Cs-Cinf` 边界势差，任何一项定义不同都可能造成小时级差异。
3. Q4 的收缩不能删除；固定半径会使 72 h 内仍未达标。当前 PCHIP/线性插值差异很小，因此剩余约 0.35 h 不太可能来自插值类型本身，更应检查移动边界通量、Jacobian、干固体密度闭合和水分库存口径是否与参考答案相同。
4. 当前修正版的 Q3/Q4 残差约 `5e-11`、水分平衡误差约 `1e-9`，所以现阶段更像是模型参数/边界口径差异，而不是线性方程没有收敛。

下一步若要对齐截图答案，优先级应为：

`D(C,T) 与 h_m 的定义/数值` → `Q4 移动边界守恒口径` → `4 h 后 C_inf 延拓` → `h、k、rho、c_p`。

# A题高温作业服：范文图表学习与取舍

## 样本覆盖

- `【优秀论文】高温作业服设计.pdf`：31页，有文本层；主要图包括一维传热模型、材料接触面、离散示意、实测—模拟拟合、时间—空间温度分布、稳态剖面、阈值温度历程、不同厚度曲线与双厚度优化图。
- `A001.pdf`、`A022.pdf`、`A171.pdf`：共124页中的扫描型论文样本，按页渲染检查。共同使用力学/传热结构示意、时序拟合、二维或三维响应面、优化曲线与参数检验。

## 保留的有效做法

1. 第一问先画“层—边界—观测点”示意，使偏微分方程与实际结构可对应。
2. 拟合图必须与误差指标配套；本方案进一步增加残差子图，避免只看两条重合曲线。
3. 时空温度场和若干关键时刻剖面承担不同阅读任务，应分开：前者看传播过程，后者看各层温降贡献。
4. 厚度优化必须显示安全阈值、活跃约束和最小可行解，而不是只给最终数值。
5. 双厚度设计用二维可行域和约束边界表达，推荐点必须显示距边界的裕量。

## 明确不照搬的做法

1. 不用透视3D曲面代替二维可行域；透视会遮挡边界并使读数困难。
2. 不以高频振荡的算法迭代曲线证明物理模型正确；若迭代曲线不能回答收敛问题，则删除或放附录。
3. 不把“拟合看起来贴合”当作外推验证；增加残差、误差定义和校准/验证边界。
4. 不用彩虹色图，不让颜色独自承担组别或可行性含义。
5. 不复制范文数据、图形或结论；范文只用于学习证据组织和版式。

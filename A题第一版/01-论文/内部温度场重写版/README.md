# 内部温度场重写版

这是在原论文旁边新建的独立版本。问题二至四使用显热传导方程计算药材内部温度，并将 `T(r,z,t)` 反馈给状态相关扩散系数；旧论文和旧版求解器没有被覆盖。

- PDF：`内部温度场重写版.pdf`
- LaTeX 源：`内部温度场重写版-LaTeX/内部温度场论文.tex`
- 新版程序：`内部温度场重写版-LaTeX/code-sources/`
- 新版结果：`内部温度场重写版-LaTeX/results/`
- 计算审计：`内部温度场重写版-LaTeX/revision-manifest.json`

本版计算的是无潜热显热温度场。若要计算含汽化潜热模型，仍需补充潜热/相变焓、相变动力学或气液平衡关系、气相传输参数；内部多点实测温度和含水率用于验证，目前也未提供。

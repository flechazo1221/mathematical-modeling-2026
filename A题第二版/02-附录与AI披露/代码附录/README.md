## 可计算性结论

- 仅考虑内部显热温度场：现有数据足够。附件和题面已提供初始温度、烘房温度时间序列、密度/比热/导热系数经验式、传热系数和几何尺寸。
- 若加入潜热耦合：现有数据不足以唯一计算。缺少汽化潜热（或相变焓）、蒸发/相变速率或气液平衡关系，以及内部温度/含水率实测用于验证；若采用气相传输模型，还缺少孔隙率、渗透率和内部蒸汽分压等参数。

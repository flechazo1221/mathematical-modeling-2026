# A题第二版：正式投稿整理包

本目录把内部温度场计算论文按正式投稿口径整理为唯一提交入口。正文不保留工作流版本标记，Q2—Q4 采用同步求解的无潜热显热温度场；原始第一版完整保存在 `../A题第一版/`，未被覆盖。

## 主要文件

- `08-paper/完整论文.pdf`：编译通过的投稿 PDF，共 39 页。
- `08-paper/完整论文-LaTeX/完整论文.tex`：唯一正文源文件。
- `08-paper/构建记录.json`：源文件、PDF、求解器和结果哈希及质量检查记录。
- `08-paper/AI使用声明.md`：事实化 AI 使用披露。
- `03-计算与结果/温度场计算/`：实际执行的求解器、运行日志和 CSV 结果。
- `05-图表/温度场图件/`：论文所用图件、数据快照和图件合同。

## 提交前必须人工完成

1. 在 LaTeX 源文件的队伍信息字段中补齐报名号、学校和成员信息。
2. 按当届官方规则确认 AI 披露格式、文件命名和上传要求。
3. 对论文中的模型假设和无潜热适用边界进行队伍最终确认。

# 候选模型方案（H2 选择材料）

## 公共比较口径

所有候选使用同一附件、同一角度分组、同一预先冻结窗口、同一原始/有依据掩码配对、同一单位与残差定义。不得随机拆分相邻谱点。复杂候选必须与能回答同一决策问题的简单基线比较；任何例外须在运行前记录。

## 家族 B：局部条纹两束基线（所有相关问的共同起点）

对每个角度、每个预注册窗口检测同类相邻极值，以中位 `Delta_sigma` 及离散度给出 `d(n)` 条件曲线或给定待批准 `n` 区间下的厚度区间。双角先独立计算，后比较光学厚度一致性。非等距波数直接用原坐标做极值间距，不把索引差当波数差。

- 覆盖：Q1.1、Q2.1–Q2.3、Q3.4–Q3.6、I1–I2；Q3.3/Q3.7以其残差或不一致为参照。
- 成本：低；可解释、可运行。
- 失败：不足一个完整条纹、极值不稳定、不同窗口漂移明显、n完全自由导致d不可识别。
- 依赖假设：A1–A3、A6，均 **等待队长确认**。

## 家族 F：等距波数 FFT 光学厚度候选

先在预注册窗口把谱插值到等距波数网格，记录插值器、步长、窗函数和零填充；FFT峰只估计光学厚度/初值，不直接当唯一物理厚度。L04明确要求倒波长（波数）等距采样，并提示窗口、泄漏、混叠和色散限制。[L04, PDF p.2、p.4–5]

改进链：`B → 极值稀疏或人工配对不稳（待检验） → 全窗口频率估计 → 重采样/窗口变化下峰位更稳定且合成恢复通过 → 峰不唯一、漂移超过预注册门槛或不能改善双角一致性则拒绝F并回到B`。

- 实质差异：由局部极值间距改为全窗口频域估计。
- 风险：插值与窗函数可制造/移动峰；色散导致展宽或莫尔结构。
- 依赖假设：A1、A3、A7，均 **等待队长确认**。

## 家族 P：两束物理谱约束回归候选

以B或F提供初值，在原始非等距波数坐标上拟合低维两束谱：相位严格含角度，振幅/基线只用预注册低维项；n(sigma)保持符号族或待批准有界参数，不自行填入文献缺失值。先逐角，再比较共享d的联合版本。L04允许“FFT初值→非线性回归”作为候选，但数值拟合改善不证明真实厚度更准。[L04, p.8、p.11]

改进链：`B/F → 相位曲率、跨窗漂移或极值利用不足（待检验） → 在原坐标做物理相位回归 → 结构残差下降、合成恢复和多初值稳定，同时n-d剖面可辨 → 若仅RMSE下降、参数贴边/高度相关或双角恶化，则拒绝P`。

- 实质差异：显式拟合完整观测序列而非只用周期摘要。
- 可识别性：必须报告剖面损失、参数相关、边界命中与等价解；若n尺度自由，返回条件厚度而非唯一d。
- 依赖假设：A1/A2/A5/A6/A7，均 **等待队长确认**。

## 家族 M：复折射率分层多光束候选（条件准入）

用Fresnel界面系数和传播相位/衰减构造单层传输矩阵或等价Airy反射式，允许复折射率；必须能在后界面反射趋零、强衰减或去相干极限退化到两束/无条纹基线。[L02, p.7, Fig.2；L04, p.2]

改进链：`P/两束 → 双角一致的结构残差且替代解释不能充分说明（待检验） → 增加多次反射分母/复振幅 → 跨窗、双角、合成消融均显示可重复的厚度影响 → 若机制证据或厚度影响任一不支持、参数不可识别、增益不稳定，则拒绝M并保留简单基线`。

- 覆盖：Q3.1–Q3.9；对SiC仅在Q3.7两项证据均支持后进入Q3.8/Q3.9。
- 多光束必要条件候选：相关界面反射非零；后续返回振幅未被吸收/粗糙/楔度/有限相干完全抑制；相位关系在仪器分辨率内可观测。必要条件不构成存在证明。
- 替代解释：色散、吸收、低频仪器基线、楔度/粗糙度、异常测量。
- 依赖假设：A4/A5/A7，均 **等待队长确认**。

## 三态判断与有条件修正

- `存在`：机制必要条件未被否定，且M相对P在预注册的双角、跨窗、结构残差/消融检查中均有稳定证据，并显示超过队长确认门槛的厚度影响。
- `未获支持`：在验证能力足够的窗口内，M未稳定优于P或厚度影响低于门槛。
- `证据不足`：n/k、相干、分辨率或可识别性不足以区分M与替代解释。

阈值本阶段不编造；A7 **等待队长确认**。对SiC，只有“机制存在获支持”且“厚度影响获支持”同时成立才设计执行修正；否则Q3.8/Q3.9返回未触发理由。

## 非约束性建议

H2可优先批准“B为必保底 + F或P择一原型诊断”，把M设为条件分支；这只是风险/成本排序建议，不是路线选择。若匹配线性n/k仍缺失，所有路线应优先输出光学厚度或n区间条件结果。

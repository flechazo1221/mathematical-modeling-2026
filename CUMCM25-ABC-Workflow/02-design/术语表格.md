# 术语与符号表

|符号/术语|定义|单位/域|备注|
|---|---|---|---|
|`sigma_i`|第i个波数|cm^-1|严格递增，非精确等距|
|`lambda_i`|真空波长 `10^4/sigma_i`|μm|只作单位换算|
|`R_percent`|附件原始反射率|%|保留>100及首点0|
|`R_i`|建模比例 `R_percent/100`|无量纲|异常不自动裁剪|
|`theta_0`|空气侧入射角|deg/rad|10°或15°|
|`theta_1`|外延层内折射角|rad|由Snell关系定义|
|`d_um`|物理外延层厚度|μm，>0|最终目标量；可能不可唯一识别|
|`d_cm`|`10^-4 d_um`|cm|用于波数相位|
|`n(sigma)`|线性折射率实部|无量纲|保持符号或待批准区间|
|`kappa(sigma)`|消光系数|无量纲，>=0|与吸收相关 [L02, p.7]|
|`n_tilde`|`n+i kappa`|无量纲|线性复折射率|
|`n2`|非线性折射率|非本题n的单位|L03中的n2不得代替n|
|`phi`|往返相位差|rad|含传播与反射相位|
|`Delta_sigma`|相邻同类极值波数差|cm^-1|局部条纹基线输入|
|`tau=2nd cos(theta_1)`|光学往返尺度|长度|谱周期主要约束量|
|`M_raw`|全量原始数据掩码|布尔|全部点为真|
|`M_reasoned`|有依据敏感性掩码|布尔|仅标记，不覆盖原值|
|内部一致性|双角、跨窗、扰动下结果相容|—|不等于真实准确度|
|真实准确度|相对独立真值的误差|μm或相对量|当前无独立真值|
|结构残差|随波数/角度呈系统模式的残差|按模型口径|用于诊断，不单独证明机制|
|可识别性|数据能否区分参数组合|—|重点检查n—d耦合|
|多光束三态|存在/未获支持/证据不足|枚举|不得把证据不足写成不存在|
|失败返回|不满足识别/分辨/边界时的显式状态|枚举|不强制输出唯一厚度|

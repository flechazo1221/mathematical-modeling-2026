## 1. H1范围与阅读问题

本阶段服务于2025年B题“碳化硅外延层厚度的确定”，论文按2026全国规则执行。阅读聚焦：干涉测厚的物理量与边界；反射谱厚度估计的方法、验证及失效条件；折射率、吸收、掺杂、波段和角度的迁移限制；多光束、楔形和衬底吸收的潜在影响。H1冻结的15项验收任务及全部决策保持不变。本阶段没有批准、引入或冻结新建模假设。

## 3. 逐篇证据卡

### L01：重掺杂硅自由载流子吸收

- 研究对象为磷/硼扩散的平面抛光硅片；参数化适用波长1000–1500 nm、掺杂浓度约10^18–3×10^20 cm^-3，并处理测量不确定性。[L01, PDF p.2, 摘要与Sec. II]
- 自由载流子吸收随载流子密度和波长变化；既有参数化差异显著，不能脱离样品、波段和浓度任选关系。[L01, PDF p.2, Sec. I–II]
- 实验约8°入射、800–1500 nm，并用参考束及反射标准校正；与本题波段、样品和仪器并不天然等价。[L01, PDF p.5, Sec. III.B–C]
- 作者给出95%置信区间，并承认低于10^18 cm^-3时测量固有不敏感，且该影响未被样本集纳入不确定性分析。[L01, PDF p.9, Fig. 8与Sec. IV.D]
- 可迁移的是吸收依赖波长/载流子状态及参数化须带适用域；不得把其系数直接用于本题或当作SiC线性折射率。

### L02：楔形薄膜、吸收衬底和多界面反射

- 文献评述并推导楔形薄膜位于吸收衬底时的透射/反射式；常见简化包括透明厚衬底与小楔角，更完整表达以较高计算代价覆盖这些条件。[L02, PDF p.2, 摘要]
- 在线性、非磁、各向同性条件下，复折射率由实部n和消光系数κ组成，κ关联吸收；本文明确聚焦线性材料。[L02, PDF p.7, Sec. 3–4]
- 多界面产生前向/后向波及多次反射；传播矩阵基于分层介质和层内材料性质恒定等条件。[L02, PDF p.7, Fig. 2与Eqs. (7)–(10)]
- 文献区分均匀厚度与楔形，并给出高楔条件Δd>λ/(4n)；斜入射、粗糙度、纹理和缺陷也会改变响应。[L02, PDF p.6, Sec. 2–3]
- 忽略衬底吸收可能产生非零RMSE；示例κ2=10^-6、Δd=30 nm时近似式RMSE为0.465%。这只是特定设定的示例，不能作为本题阈值。[L02, PDF p.13, Sec. 7与Table 2]

### L03：SiC光子学综述

- 综述覆盖SiC光子平台、多型、生长/制备、微腔和集成光子应用，重点并非外延层红外反射测厚。[L03, PDF p.1, 摘要与Sec. 1]
- Table 1同时列出折射率n和非线性折射率n2，二者是不同物理量；综述强调高折射率、宽禁带及二/三阶非线性。[L03, PDF p.2, Table 1]
- 3C、非晶及4H-SiC的n2数值来自波导/微谐振器非线性实验，并涉及多型和偏振差异。[L03, PDF p.5, Sec. 2]
- 多型、制备、界面和工艺可导致不同损耗；不同SiCOI制程各有材料损耗及表面质量限制。[L03, PDF p.2–3, Fig. 1附近]
- 该综述只能支持材料/波段/多型迁移风险；没有给出可直接用于本题的线性红外n(λ,N)参数化，尤其不得把n2当作n。

### L04：反射谱FFT厚度估计

- 对透明或半透明薄膜，作者把非线性回归用于很薄的膜，把FFT视为约1 μm以上的快速方法；实际下限还取决于折射率和至少一个完整条纹。[L04, PDF p.1–2, 摘要与Sec. 2]
- 全多光束式与只保留前两束反射的简化式并列给出；两束式振荡相位含n(λ)d/λ，显示折射率与厚度耦合。[L04, PDF p.2, Fig. 1与Eqs. (1)–(2)]
- 斜入射时反射率受角度和偏振影响，层内光程也变化；主体推导主要按法向入射，不能直接替代本题10°/15°关系。[L04, PDF p.2, Sec. 2]
- FFT要求倒波长t=1/λ等距采样；原始波长通常不等距，需要插值。有限区间、离散采样、泄漏、混叠和选窗均限制分辨率。[L04, PDF p.2、p.4, Sec. 1、3]
- 色散会产生莫尔效应；有效折射率校正在强色散区会失效。硅约1100 nm带间跃迁附近宜改用局部条纹，且仍需相应波长折射率。[L04, PDF p.5, Eqs. (6)–(8)]
- FFT可作为网格搜索初值，再接非线性回归；这种增量改进需要可计算的物理谱，数值拟合改善不证明真实厚度更准。[L04, PDF p.8, Sec. 5；PDF p.11, Conclusion]

## 4. 跨文献分析：共识、冲突与证据强度

- L01、L02、L04共同支持折射率/吸收依赖材料、波长和样品状态，厚度通过光学相位进入反射谱；没有一篇给出本题SiC样品在匹配波段、掺杂和温度下可直接采用的完整n(λ,N)。
- L02说明楔形和衬底吸收可使简化式偏离；L04说明色散、采样和多光束可影响FFT。它们支持按具体缺陷增量检验，但不支持预先选择复杂模型。
- L04主体是单层、通常法向入射；L02覆盖楔形和吸收衬底但仍是一般薄膜。二者不能免除本题外延/衬底界面、10°/15°及仪器条件验证。
- L03偏纳米光子器件，许多数据是n2或器件损耗；仅能支持迁移风险，不能提供本题线性红外折射率取值。

## 5. 领域机制与可复用数学表述

1. 单层反射谱周期由相位控制，相位同时依赖d和n(λ)；n未约束时二者混淆。[L04, PDF p.2, Eqs. (1)–(2)]
2. 线性各向同性材料可写复折射率ñ(λ)=n(λ)+iκ(λ)，κ关联吸收。[L02, PDF p.7]
3. 简化两束谱含形如cos(4πn(λ)d/λ)的相位；完整式还含界面反射率和多次反射分母。[L04, PDF p.2] 提取文本损伤了公式排版，DESIGN使用时必须回看原PDF。
4. FFT自变量宜为倒波长/波数并等距采样；需明确插值、选窗和分辨率。[L04, PDF p.4]
5. 相邻条纹法需两个极值对应的折射率，且强色散时谨慎。[L04, PDF p.5, Eq. (8)]
6. 传播矩阵是处理分层介质、多次反射和复折射率的候选数学族，适用性依赖层结构、相干处理、角度、偏振及材料均匀性。[L02, PDF p.7]

以上仅供DESIGN比较，不构成H2路线选择。

## 6. 数据、参数与评价指导

- n(λ)、κ(λ)、掺杂/载流子范围、多型、温度和偏振必须记录来源与适用域；缺匹配证据时保持符号或区间。
- 保留原始数据与有依据掩码的成对分析；文献没有为附件2超100%点或四表首个零值提供自动删除依据。
- FFT/条纹候选需检查等距波数处理、窗口、分辨率、泄漏/混叠、色散敏感性和合成恢复。[L04, PDF p.4–5、p.11]
- 双角、跨窗口和重复拟合只能支持内部一致性；无独立真值不能称真实准确度。
- 多光束修正须同时有机制证据和厚度影响；L02/L04只给机制候选，不能替代题目数据检验。

# 现有知识与工具映射

本文件只提供阶段到资源类别的路由。阶段 Skill 不得一次性加载本表列出的全部资源；先读取入口，再根据当前操作打开一项最相关的 reference。

- 算法定位：`references/算法索引.md`。
- 算法全文：`assets/*.md`。
- PDF：`tools/pdf/SKILL.md`。
- Excel：`tools/xlsx/SKILL.md`。
- 论文搜索：`tools/paper_search/SKILL.md`。
- 文献获取辅助：`skills/math-modeling-literature/SKILL.md`；只负责检索、核验与开放获取下载。
- 文献精读交接：`skills/math-modeling-literature-reading/SKILL.md`；读取用户提供的全文并生成 DESIGN 的权威知识输入。
- 科研可视化引擎：`tools/figure/SKILL.md` 及其 `scripts/`、`references/`。
- Word：`tools/docx/SKILL.md`。
- LaTeX：`tools/latex/SKILL.md`。
- DESIGN 按需读取：`references/算法索引.md`、一个匹配的 `assets/*.md`，以及 `references/roles/建模手/references/` 中与当前问题直接相关的一份指南。
- COMPUTE 按需读取：`references/roles/编程手/references/` 中与语言或验证问题相关的一份指南；需要表格或诊断图时再读取对应工具 Skill。
- FIGURE 按需读取：先读 `tools/figure/SKILL.md`，再按其路由读取选图、配方或质检 reference，不整库加载。
- PAPER 按需读取：`references/roles/论文手/references/` 仅用于特定格式或写作问题，不作为独立角色入口。
- 流程 7 论文模板与题型写作库：`skills/math-modeling-paper/references/paper-template-2026/`；必须先读其中 `INTEGRATION.md`，按题型和写作任务渐进加载。该库是带 MIT 许可和固定上游提交的参考快照，不是官方规则来源。
- 范文风格画像：`shared/references/writing-style-profile.md`；基于用户提供的 2020—2025 年 57 篇、2979 页全文语料。具体覆盖边界、写作归纳和审查触发器见 `skills/math-modeling-paper/references/exemplar-*.md`。

阶段 Skill 先读自己的入口，再按当前任务需要读取上述资源。不得一次性加载全部知识，也不得因为本轮未加载而删除资源。
